## 작업 원칙

1. **작업 단위마다 확인 후 커밋한다.** 기능이나 수정이 끝나면 변경 내용을 요약해 사용자에게 확정을 요청하고, 승인을 받은 뒤에만 커밋한다. 서로 관련 없는 작업을 한 커밋에 묶지 않는다.
2. **배포는 커밋된 상태에서만 한다.** 작업 트리의 미커밋 변경을 운영에 배포하지 않는다.
3. 각 단계는 `pnpm lint`, `pnpm typecheck`, `pnpm test`를 통과해야 완료로 본다. UI 변경은 320·390·1440px와 라이트·다크 테마에서 직접 확인한다.
4. 사실 확인이 필요한 콘텐츠(경력, 성과 수치, 프로젝트 기여)는 임의로 작성하지 않고, 사용자에게 초안이나 원자료를 요청한다.
